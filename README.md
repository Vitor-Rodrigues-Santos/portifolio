# 💼 Portfólio Web - Currículo e Apresentação Profissional

[![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=for-the-badge&logo=html5&logoColor=white)]()

Este repositório contém a estrutura semântica de uma página web de Portfólio / Currículo Profissional, desenvolvida como atividade prática para demonstrar o domínio dos elementos estruturais e organizacionais do HTML5.

---

## 🚀 Tecnologias Utilizadas

- **HTML5** (Estruturação e marcação semântica de conteúdo web)

---

## 📋 Atividade Desenvolvida

### 💻 1. Página de Portfólio Pessoal (`index.html`)
- **Descrição:** Desenvolvimento de uma página estática funcional para apresentar informações pessoais, perfil profissional, competências, tabela de projetos e formulário de contato.
- **Lógica aplicada:** 
  - **Estruturação Semântica:** Utilização de tags HTML5 estruturais como `<header>`, `<nav>`, `<main>`, `<section>` e `<footer>`.
  - **Navegação Interna:** Construção de um menu no cabeçalho com links ancorados (`href="#sobre"`, `href="#projetos"`, `href="#contato"`) apontando para as seções correspondentes.
  - **Apresentação Pessoal:** Inserção de foto de perfil (`<img>`), resumo sobre a formação e habilidades técnicas em lista não ordenada (`<ul>` e `<li>`).
  - **Exibição de Projetos:** Organização dos projetos desenvolvidos em formato tabular (`<table>`, `<thead>`, `<tbody>`, `<tr>`, `<th>`, `<td>`), incluindo hiperlinks operacionais para repositórios externos.
  - **Formulário de Contato:** Agrupamento de campos dentro do elemento `<fieldset>` com legenda (`<legend>`), integrando inputs de texto (`<input>`), menu suspenso (`<select>`), área de texto (`<textarea>`) e botão de submissão (`<button>`), devidamente associados aos seus respectivos `<label>`.
  - **Rodapé Informativo:** Utilização do caractere especial (`&copy;`) para direitos autorais e links diretos para e-mail (`mailto:`) e contato via WhatsApp.
- **Conceitos:** HTML semântico, links e navegação por âncoras (`<a>`), manipulação de imagens (`<img>`), listas (`<ul>`), tabelas em HTML (`<table>`), formulários e agrupamentos (`<form>`, `<fieldset>`, `<legend>`, `<input>`, `<select>`, `<textarea>`) e caracteres especiais (entities).
